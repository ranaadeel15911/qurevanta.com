# Daily article automation

Every day at **5:00 PM** (Pakistan time), the Windows Task Scheduler task **"QureVanta Daily Article"** runs
`run-daily-article.ps1`. It starts Claude Code (bundled with the VS Code extension) in headless mode with
the instructions in `daily-article-prompt.md`: research one current US medical-billing topic, write an
original article in `src/content/blog/`, upload its image to Cloudinary (`dr3ie9gpz`, preset `Qurenanta`),
build, and push to `main` — Vercel then publishes it.

- **The PC must be on** at 5 PM. If it was off, the task runs as soon as the PC is back on (once per day).
- **Logs:** `automation/logs/` (one file per run). `last-published.txt` records the last day an article went out.
- **Skips the day** if the repo has uncommitted changes, so it never mixes with work in progress.
- **Run now:** `Start-ScheduledTask -TaskName "QureVanta Daily Article"`, or right-click the task in Task Scheduler → Run.
- **Pause / stop:** Task Scheduler → Task Scheduler Library → "QureVanta Daily Article" → Disable or Delete.
- **Change what it writes:** edit `daily-article-prompt.md`.

## Facebook and Instagram

After an article is published, `post-to-facebook.ps1` posts it to the QureVanta Facebook Page: a 1080×1350
image generated by Cloudinary (article photo, dark overlay, bold title, category and qurevanta.com), a short
caption written by the run, and the article link. It waits until the article is live before posting and
never posts the same article twice (`logs/facebook-posted.txt`).

Credentials live only on this PC, in `%USERPROFILE%\.qurevanta\facebook.json`:

```json
{ "pageId": "1234567890", "pageToken": "EAAG..." }
```

Use a long-lived **Page** access token with `pages_manage_posts` and `pages_read_engagement`.
Test without posting: `powershell -ExecutionPolicy Bypass -File automation/post-to-facebook.ps1 -DryRun`.

`post-to-instagram.ps1` then posts the same image to **@qurevanta** with an Instagram caption ending in
"link in bio" (caption links are not clickable on Instagram). It needs the Instagram account to be a
Business account connected to the Qurevanta Page, and the Page token to also include `instagram_basic`
and `instagram_content_publish`. Optional: add `"igUserId"` to `facebook.json` to skip the lookup.
